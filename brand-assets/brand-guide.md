# P²Code Brand Guide

## Name
- **Full name:** P²Code (with superscript 2)
- **Pronunciation:** "P-squared Code"
- **Plain text fallback:** P2Code (when superscript isn't available)
- **Domain:** p2code.com

## Logo Text Treatment

```
P²Code
││  │
││  └── "Code" — text-muted (#94A3B8) — lighter weight, semibold
│└──── "P²" — unified gradient accent (purple → cyan) — ONE UNIT
└───── "P²" is the brand mark. Always gradient. Never split.
```

"P²" is treated as a single gradient unit. The gradient IS the brand identity.
On light backgrounds, use the darker gradient (#6C3AED → #0891B2).

## Colors

### Primary Palette
| Name | Hex | Usage |
|------|-----|-------|
| Primary | `#6C3AED` | Buttons, links, interactive elements |
| Primary Dark | `#5B21B6` | Hover states, active states |
| Primary Light | `#8B5CF6` | Gradient start, highlights |
| Accent | `#06B6D4` | Gradient end, secondary CTAs |
| Accent Dark | `#0891B2` | Accent hover state |

### Brand Gradient
```css
background: linear-gradient(135deg, #8B5CF6, #06B6D4);
```
Used for: the "²" superscript, section headings, CTAs, decorative elements.

### Surface Colors (Dark Theme)
| Name | Hex | Usage |
|------|-----|-------|
| Surface (bg) | `#0F172A` | Page background |
| Surface Light | `#1E293B` | Cards, elevated surfaces |
| Surface Lighter | `#334155` | Borders, dividers |

### Text Colors
| Name | Hex | Usage |
|------|-----|-------|

| Text Muted | `#94A3B8` | Secondary text, "Code" in logo |

### Utility Colors
| Name | Hex | Usage |
|------|-----|-------|

## Typography
- **Font:** Inter (Google Fonts)
- **Weights:** 400 (body), 500 (medium), 600 (semibold), 700 (bold), 800 (extrabold)
- **Logo weight:** 700 (bold) for "P", superscript "²" matches
